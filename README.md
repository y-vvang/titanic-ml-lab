# Titanic ML Lab - 泰坦尼克号机器学习科普网站

## 项目简介

一个交互式机器学习科普网站，以经典的泰坦尼克号生还预测二分类问题为案例，让小白学习者亲身走完完整的 ML 流程。

## 核心功能

### 五步交互式 ML 流程

1. **数据探索** — 6 张可视化图表帮助理解数据特征与生还关系
2. **数据清洗** — 选择缺失值填充策略、勾选特征、调整权重
3. **模型训练** — 选择模型（逻辑回归/决策树/随机森林）、配置超参数、实时训练日志
4. **模型评估** — 准确率/精确率/召回率/F1、混淆矩阵、特征重要性、分组准确率
5. **自定义预测** — 输入乘客信息，获取生还概率仪表盘

### 技术亮点

- **真实训练**：后端 Python sklearn 实时训练，非预制结果
- **SSE 流式**：训练过程实时推送进度日志
- **暗色科技**：毛玻璃风格 UI，适合数据可视化场景
- **完整流程**：从原始数据到最终预测的端到端体验

## 数据集

泰坦尼克号乘客数据（891 条记录），各列含义：
- PassengerId: 编号 | Pclass: 船舱等级 | Name: 姓名 | Sex: 性别
- Age: 年龄 | SibSp: 兄弟姐妹/配偶数 | Parch: 父母/子女数
- Ticket: 票号 | Fare: 票价 | Cabin: 舱位 | Embarked: 登船港
