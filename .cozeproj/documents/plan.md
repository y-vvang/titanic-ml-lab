# 计划：修复并改进 /train 训练页

## 概述
改进 /train 页面的训练日志和学习曲线。训练日志需更详细，展示训练全过程的每个步骤；学习曲线改为实时流式推送的"股票线"风格折线图，数据点更密、带渐变填充和十字准星交互。平台：Web。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 训练日志 | Python 端增加细粒度 log() 调用，SSE 流式推送 | 现有架构已支持 SSE log，只需增加日志点 |
| 学习曲线数据 | 增加更多 train_sizes 采样点（20个），SSE 逐点流式推送 | 类股票线需要更密集数据点 + 实时流式感 |
| 学习曲线图表 | 纯 SVG React 组件，渐变填充 + 悬停十字准星 + tooltip | 无需引入额外图表库，保持轻量 |
| 日志时间戳 | 前端记录每条日志的真实到达时间 | 当前 new Date() 渲染时间不一致 |

## 功能模块

### 1. 训练日志增强（Python 端）

在 `ml_engine.py` 的 `train()` 函数中，增加以下详细日志点：
- 数据加载阶段：文件路径、行数、列数、数据类型
- 数据清洗阶段：每种缺失值策略的具体处理结果（填充值、删除行数等）
- 特征编码阶段：独热编码扩展的列数、最终特征维度
- 训练集划分：训练/测试集样本数、正负样本分布
- 模型创建：每个超参数的完整配置
- 训练过程：拟合开始/结束、耗时估算
- 学习曲线：开始计算、每个 CV fold 进度
- 模型结构：解析开始/完成
- 评估：逐项指标输出、分组统计结果

日志格式保持现有 `{"type": "log", "message": "..."}` 结构，增加 `{"type": "progress", "message": "...", "detail": {...}}` 格式用于结构化日志。

### 2. 学习曲线改进

**Python 端**：
- `train_sizes` 从 6 个点增加到 20 个点：`np.linspace(0.05, 1.0, 20)`
- 逐点流式推送：每完成一个 train_size 的 CV 计算就立即推送一个 `{"type": "learning_curve_point", "data": {...}}` SSE 事件
- 数据结构：`{ trainSize, trainScore, trainScoreStd, valScore, valScoreStd, index, total }`

**前端**：
- `LearningCurve` 组件重写为"股票线"风格：
  - 更宽的 viewBox (640x300)
  - 双色渐变填充（训练线紫色渐变、验证线青色渐变）
  - 鼠标悬停显示十字准星 + tooltip（显示具体数值）
  - 数据点逐点绘制的动画效果
  - 标准差区域用半透明带状填充
  - 平滑曲线用 Catmull-Rom 样条插值（代替直线 polyline）

### 3. 日志时间戳修复

前端记录每条日志的 `timestamp`，在渲染时使用该时间戳而非 `new Date()`。
